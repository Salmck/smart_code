# 平台官方图标目录

把各平台的**官方图标文件**放到本目录，二维码中心标会自动改用图标；
没放图标的平台自动回退为「平台色 + 平台名文字」徽章。

## 文件命名（必须完全一致）

```
抖音.png
小红书.png
微信朋友圈.png
微信社群.png
公众号.png
视频号.png
美团.png
大众点评.png
线下海报.png
桌贴.png
老顾客转介绍.png
其他.png
```

支持 png / jpg / webp；建议 **256×256 以上正方形、透明底 PNG**。
放入后无需重启，下一次下载「平台标PNG」即生效。

## 官方素材从哪拿

- 微信系（朋友圈/社群/公众号/视频号）：微信公开课/微信品牌设计资源
- 抖音：抖音开放平台 · 品牌资源（Brand Assets）
- 小红书：小红书商业化品牌规范
- 美团 / 大众点评：美团开放平台品牌资源

> ⚠️ 各平台 logo 为其注册商标，请从官方渠道获取并遵守其品牌使用规范；
> 本项目不内置、不分发任何第三方商标素材。
